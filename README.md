# 3D 폰 — 켜고, 밀고, 던지기

브라우저에서 돌아가는 3D 휴대폰 장난감입니다. 전원 버튼을 꾹 눌러 켜고, 화면 안을 밀어 보고, 폰을 뒤집거나 집어 던질 수 있습니다.

## 실행

빌드 과정이 없는 정적 사이트입니다. 다만 ES 모듈을 쓰기 때문에 `index.html`을 더블클릭해서는 열리지 않고, 간단한 웹 서버가 필요합니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000` 을 엽니다. GitHub Pages 같은 정적 호스팅에 그대로 올려도 됩니다.

## 조작법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 전원 켜기 / 끄기 | 폰 오른쪽 옆면의 전원 버튼(또는 아래 `⏻ 전원` 버튼, 키보드 `P`)을 **약 1초간 꾹** 누르기 |
| 화면 잠그기 / 깨우기 | 켜진 상태에서 전원 버튼을 짧게 누르기 |
| 잠금 해제 | 화면을 위로 밀기 |
| 홈 화면 넘기기 | 화면을 좌우로 밀기 |
| 앱 열기 / 닫기 | 아이콘 누르기 / 화면 아래 막대를 위로 밀기 |
| 폰 돌리기·뒤집기 | 폰 바깥 빈 곳을 끌기, 또는 `뒤집기` 버튼(`F`) |
| 폰 던지기 | 폰 테두리나 뒷면(화면이 꺼져 있으면 화면도 가능)을 잡고 휙 끌다가 놓기, 또는 `던지기` 버튼(`T`, 스페이스) |
| 다시 집어 들기 | 바닥에서 멈추면 잠시 뒤 자동으로, 또는 `집어 들기` 버튼(`R`) |

`손전등` 앱을 켜면 폰 뒷면 플래시에서 실제로 빛이 나옵니다.

## 구조

- `index.html` — 페이지와 아래쪽 버튼, 안내 문구
- `src/main.js` — 3D 장면, 폰 모델, 물리(던지기·충돌), 입력 처리
- `src/screen.js` — 폰 화면 안의 작은 OS(부팅, 잠금 화면, 홈 화면, 앱). 2D 캔버스에 그려 폰 화면의 텍스처로 씁니다
- `vendor/` — [three.js](https://threejs.org) 0.187 (MIT), [cannon-es](https://github.com/pmndrs/cannon-es) 0.20 (MIT)
